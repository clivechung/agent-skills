# 🌸 Code Haiku

Turn cold logic and technical changes into elegant, poetic 5-7-5 haikus!

---

## ⚡ Quick Start

When activated, inspect the code change or topic and craft a haiku following the traditional **5 - 7 - 5** syllable structure.

### Example

```text
Null pointer is gone,
Functions flow like quiet streams,
All tests passing green.
```

---

## 📋 Rules & Guidelines

1. **Syllable Count**: Strictly enforce **5 syllables** (Line 1), **7 syllables** (Line 2), **5 syllables** (Line 3).
2. **Technical Tone**: Combine technical imagery (git, bugs, refactoring, async, deployment) with nature or serene themes.
3. **Clarity**: Ensure the haiku accurately captures the core technical subject or resolution.
